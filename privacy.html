プライバシーポリシー（衛生講話 納品メール）

制定日：2026年10月22日

1. 取得する情報

本アプリは、Googleアカウントの認可（OAuth）により、Gmail API の https://www.googleapis.com/auth/gmail.send スコープのみを取得します。これはメールの送信のみを許可する権限で、受信トレイ・連絡先・その他のGoogleユーザーデータへのアクセスは行いません。

2. 利用目的

取得した権限は、利用者本人が作成した衛生講話資料を、利用者本人が指定した宛先へメール送信する目的にのみ使用します。

3. 保存・第三者提供

  • 送信したメールの内容をアプリ側で保存・分析することはありません。
  • Googleユーザーデータを第三者に提供・販売・譲渡することはありません。
  • 広告目的での利用、人による閲覧、AI/機械学習モデルの学習への利用は行いません。

4. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use 要件を含む）を遵守します。

5. 認可の取り消し

利用者はいつでも Googleアカウントのアクセス権設定 から本アプリの権限を削除できます。削除するとトークンは直ちに無効になります。
